# Дополнительные правила ревью для нейронки

Этот файл вставляется в основной промпт проверки теста и может свободно
редактироваться — без пересборки скрипта/.exe.

## Размер теста

- Замечание о размере теста добавляй ТОЛЬКО если строк в файле больше 1000.
- Если строк не больше 1000 — про размер не упоминай.
- При превышении — посоветуй вынести повторяющиеся блоки в экспортные сценарии
  или разбить на несколько файлов.

## Общие требования к замечаниям

- При наличии исправлений указывай конкретное место (шаг/строку), куда его внести.
- Не выдумывай замечания, которых нет в чек-листе или этих правилах.
